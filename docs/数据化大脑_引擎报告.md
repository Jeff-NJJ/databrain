# 数据化大脑 · 第一版引擎报告

> 地基：Ombre-Brain（`P0lar1zzZ/Ombre-Brain`）+ 本地内分泌引擎（v2.0）
> 本文记录：这套整合到底改了什么、为什么这么改、以及**自己跑出来的问题**

---

## 一、先说结论

杰夫的核心命题落地成了三条可验证的工程约束：

| 命题 | 工程实现 | 验证方式 |
|---|---|---|
| 情感永久，情绪短暂 | 三层结构分离（倾向 / 慢变量 / 账本） | 180 天轨迹：想倾持久、情绪瞬时回落 |
| 历史认定不可压缩 | Event 只增不改；摘要只做索引 | `Ledger.integrity_check()` 校验 id 连续与时间单调 |
| 旧判断可更新，但要有经历 | 五段式再巩固（门控→阻抗→累积→窗口→留痕） | 汤姆 180 天重评 14 次，原始值从未被覆盖 |

---

## 二、三层架构

```
第一层  Dispositions  可触发的长期倾向（一组带阈值的按钮）
         ↓ 被按下才放电
第二层  State         激素快变量 + 心境/关系温度慢变量
         ↓ 偏置当下的解读
第三层  Ledger        append-only 事件账本 + 记忆桶
         ↑ 反过来加固/改写第一二层
```

支撑这份设计的理论源头见 `knowledge/` 下五份资料，其中三条与本项目直接咬合：

- **SS-RIF**（Cuc, Koppel & Hirst 2007, *Psych Science* 18(8):727–733）群体对话会让人共同遗忘 → "历史认定由所有人共同维护"的实验证据
- **社会评价威胁**（Dickerson & Kemeny 2004）皮质醇 d=0.67，叠加不可控 d=0.92 → 社会维度不是装饰
- **Heise 的 Affect Control Theory** EPA + deflection → 社会学里唯一接近可写码的情感定量模型

## 三、相对 Ombre-Brain 改了什么

原版 `decay_engine.py`：

```python
emotion_weight = base + arousal * arousal_boost        # 只用 arousal
```

**valence 完全没被使用，也没有任何激素层。** 这就是接入口。

### 改动清单

| # | 改动 | 理由 |
|---|---|---|
| 1 | 增补效价偏离度加成 `\|v-0.5\|*2*valence_boost` | 原版白白浪费了 valence 字段 |
| 2 | 新增隧道记忆效应 | 负性高唤醒 → 外围细节额外受损（不是得分下降） |
| 3 | `act^0.3` 加上限 3.0 | 否则长期陪伴让 score 无限膨胀，永不遗忘 |
| 4 | importance 同向强化改渐近饱和 | 原版每次 +0.15，34 次后顶到 10 |
| 5 | **编码调制**：`importance × encoding_modulation` | 把内分泌接进"写入瞬间"，而非事后调曲线 |
| 6 | 皮质醇对记忆的**倒 U** 建模 | 文献里最强的非线性，中等增强、过高损害 |

第 5 条是关键。内分泌真正影响记忆的位置是**编码那一刻的状态**，而不是事后给衰减曲线打折 —— 这是生物学正确的做法，也是原始引擎完全没有的一层。

## 四、再巩固：五段式

用户拍板：**允许更新，但必须有经历作为触发条件。**

```
① 门控     客体一致 / 记忆已满 24h / 显著性达标 / 冷却期已过
② 阻抗     age(饱和) + 原始唤醒 + 重复提取次数
③ 累积     反证据按 salience × contrast 累积，本身也随时间衰减
④ 窗口     达到阈值才开窗；单次位移有硬上限，且除以 (1+阻抗)
⑤ 留痕     原始 valence0/arousal0 只读；每次改写记入版本链
```

两条刻意设计的性质：

- **单次事件永远翻不动深记忆。** 一次好行为洗不掉长期的伤害。
- **同向证据不改写，只加固。** 只有反向才累积成反证据。

## 五、自己跑出来的问题（都已修）

跑之前我觉得这套东西没问题。跑完发现 6 个。

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 皮质醇 21.5% 时间贴在下界 | 拮抗矩阵按"每单位时间位移"施加；原引擎的量级是按每轮对话设计的，改到小时级后放大几十倍 | 拮抗改为作用于**调定点**，且只看激素偏离自身基线的部分 |
| 2 | `importance` 顶到 10 | 每次同向强化 +0.15，无饱和 | 改为渐近饱和 `+0.18*(9.8-imp)/9.8` |
| 3 | `score=41`，永不遗忘 | `act^0.3` 无上限 | 加 `min(3.0, act**0.3)` |
| 4 | 30 天零重评 | 阈值 2.50 vs 实到 1.54；阻抗主因是重复提取项（34 次顶满） | repeat 权重 0.10→0.035、上限 1.0→0.6；阈值 1.0→0.65 |
| 5 | 版本链丢失方向 | `shift` 存的是无符号量 | 存 `signed = new_v - old_v` |
| 6 | 重评时唤醒纹丝不动 | 旧公式乘的是一个接近 0 的小差值 | 唤醒按与效价**同一比例**向新证据移动（才算真的"去激化"） |

另外一处：`intensity` 原本只影响唤醒和显著性，**不影响效价** —— 于是"救命之恩"和"举手之劳"产生完全一样的感受。已修：`v = 0.5 + (v-0.5)*(0.55+0.45*intensity)`。

## 六、实验结果

### 主模拟：汤姆的 180 天

```
valence  0.272 ──► 0.548      drift +0.277
重评     14 次                  原始事件 826 条，一条未删
阻抗     0.44 ──► 1.68
```

移动幅度递减，这是最想看到的一条：

```
+0.1119 (D5,   阻抗 0.44)
+0.0770 (D13,  阻抗 0.60)
+0.0563 (D37,  阻抗 1.08)
+0.0460 (D48,  阻抗 1.18)
...
+0.0243 (D174, 阻抗 1.68)
```

**越深的判断，越难再被撼动。** 期间有涨有跌（D28 conflict −0.041、D95 loss −0.043、D151 criticism −0.027），不是单调美化。

### 种子扫描（排除过拟合）

5 个种子全部零 FAIL 零 WARN，终值标准差 0.033 —— 结论不依赖特定随机序列。

### 对照实验

**B · 前 60 天伤害 → 后 120 天善意**

```
初始 0.054 → 60 天 0.054（伤害期纹丝不动，全是同向加固）
          → 180 天 0.333
```

前 60 天纹丝不动**是正确行为**：持续的恶意对既有判断没有"反驳"作用，它只是把判断钉得更深。

**C · 撬动一条深负性判断需要多少次经历**

基线：`valence=0.054`（30 天伤害造成），阻抗 1.62

| 经历类型 | 首次撬动 | 40 次后 |
|---|---|---|
| 日常善意 affection | 第 5 次 | 0.353 |
| 深度共处 shared_joy | 第 4 次 | 0.404 |
| 重大和解 reconciliation | 第 5 次 | 0.321 |

**涌现出来的结论（非预设）：持续的日常善意比一次性的重大和解更有效。** 依恋本身就是靠日常积累的，不是靠单次赎罪。模型自己跑出了这一点。

## 七、已知限制 / 下一步

1. **缺主题层。** 现在只有「客体级」（汤姆）和「情节级」，没有中间的 "汤姆在工作上抢功" 这类模式层。Ombre-Brain 的 `domain` 字段可以承担这个。
2. **反馈回路没有外部观测者。** "分布式持有的历史认定"目前还是单副本。要真做持有多份完整拷贝 —— 那才是 SS-RIF 的完整形态。
3. **epa/deflection 未接。** Heise 的 ACT 已在资料里，但还没并进 `appraise()`。
4. **参数是手调的。** 现在的值自洽但不是拟合出来的，需要拿真实对话数据标定。
